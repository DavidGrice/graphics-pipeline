# blender-pipeline

Headless PNG → GLB. **No EEVEE.**

| Item | Value |
|------|-------|
| Docs / CI pin | **Blender 5.2.3 LTS** |
| Supported range | **≥ 4.2** (`bpy.app.version`) |
| Binary | `BLENDER_BIN` env, else `blender` on PATH |
| Mode | `--mode billboard` (default) or `--mode rigged` (`MODE` / `SMOKE_MODE`) |

```bash
export BLENDER_BIN=/path/to/blender   # optional
./pipeline.sh /path/in.png /path/out.glb

# billboard (default): mesh plane + Action `spin` (no armature)
MODE=billboard ./pipeline.sh in.png out.glb

# rigged: mesh + armature + vertex weights + Actions `idle` + `walk` + `run` + `jump`
MODE=rigged ./pipeline.sh in.png out-rigged.glb

# equivalent — args AFTER --
"${BLENDER_BIN:-blender}" --background --python png_to_glb.py -- in.png out.glb --mode rigged
```

Version check:

```bash
"${BLENDER_BIN:-blender}" --background --python blender_version.py
```

OBJ is **not** an animated output path (GLB only for clips/skins). No Rigify / Mixamo.

## Orchestration

```bash
./run_mvp.sh hero-billboard
# → inbox PNG (or smoke demo) → pipeline.sh | make_demo_glb.mjs → register_asset.mjs
```

`make_demo_glb.mjs` is **DEMO ONLY** when Blender is absent. CI should pin Blender **5.2.3 LTS** and run `png_to_glb.py`.


## S2-A Windows live smoke

Fail-closed path (no `make_demo_glb` substitute).

**Do not** point `BLENDER_BIN` at Microsoft Store `blender-launcher.exe` — use the official installer `blender.exe` (typically under `C:\Program Files\Blender Foundation\Blender 5.2\`). Any `*.png` in the inbox folder works; `YYYYMMDD-HHMMSS` naming is only the `export_png` convention.

```powershell
$env:BLENDER_BIN = "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"
$env:SMOKE_LIVE = "1"
# Krita GUI + MCP Bridge running; real PNG already in data/inbox/s2a-smoke/ (or export first)
.\apps\blender-pipeline\smoke_live.ps1 s2a-smoke
```

Git Bash / WSL: `SMOKE_LIVE=1 ./apps/blender-pipeline/smoke_live.sh s2a-smoke`

Optional S2-C: `$env:SMOKE_MODE = "rigged"` (or `billboard`) before smoke.

Health is **red** if the Krita MCP bridge (`127.0.0.1:9797`) is down. CI stays on the non-live / demo path without Windows.

`png_to_glb.py` builds a manual textured plane (not `import_as_mesh_planes`) so Blender 5.2 glTF export gets a valid mesh; atomic temp files use `*.tmp.glb`.


## S2-D CI Blender smoke

GitHub Actions job `blender-smoke` (matrix rows A/B) downloads **Blender 5.2.3 LTS** on `ubuntu-latest`, sets `BLENDER_BIN`, runs `pipeline.sh` against `tests/fixtures/smoke-8x8.png` (generated by `scripts/ensure-smoke-png.mjs` if absent), then asserts with `scripts/s2d-assert-glb.mjs`.

| Env key | Billboard | Rigged |
|---------|-----------|--------|
| `SMOKE_MODE` / `MODE` | `billboard` | `rigged` |
| `S2D_CLIP_EXPECT` | `spin` | `idle,walk,run,jump` |
| `S2D_EXPECT_ARMATURE` | `0` | `1` |
| `S2D_EXPECT_WEIGHTS` | `0` | `1` |
| `S2D_STAGE_EXPECT` | `mvp-billboard` | `rigged` |

Fail-closed if Blender missing or assert mismatches. Unit `build-test` stays Blender-free.
